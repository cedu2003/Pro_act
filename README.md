# Pro Act - Simple React (Vite) Starter

This is a simple React starter for the Pro Act project (black & white theme).

## Included
- Home, Courses, Login, Owner pages
- Simple styling (styles.css)
- Vite config (use `npm install` then `npm run dev` locally)

## Deploy
Upload the project files (not the zip) to GitHub & connect to Vercel. Vercel will auto-deploy.
